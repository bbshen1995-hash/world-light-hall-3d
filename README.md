# 世界之光主堂 3D

世界之光聖教會主堂的可編輯 3D 模型。整個網頁是單一 HTML 檔，下載後雙擊就能離線開啟。

線上版：https://bbshen1995-hash.github.io/world-light-hall-3d/

## 可以做什麼
- 排座位：座位區塊可以改排數、每排張數，也可以做成扇形。畫面會即時顯示總座位數。
- 擺喇叭：量任兩點的距離和聲音到達時間。放一個聆聽點，會列出每顆喇叭的距離與到達時間。
- 看視線：切到「座位視線」，點地板任一處，就換成坐在那裡看舞台。
- 對照拍攝視角：切到「拍攝視角」，鏡頭回到現場影片的拍攝位置。拖時間軸可以跟著影片移動和轉身，也能把原始影格疊在畫面上比對。
- 存檔與匯出：修改會存在瀏覽器裡，可以另存多套配置。也能匯出 JSON 備份，或匯出 GLB 給 Blender 使用。

## 尺寸從哪裡來
- 平面外框、舞台、柱位、座位：取自掃地機器人的清掃地圖。比例用現場實測的控台區寬 299.5 cm、深 131 cm 換算，誤差約 ±3%。
- 地磚 80 cm、控台區寬與深：現場實測。
- 喇叭外形：JBL VRX932LAP、Turbosound TL-1201 的原廠規格。
- 入口店面玻璃與拍攝視角：從現場影片的關鍵影格反推，殘差 2 到 16 像素。
- 天花板高度、舞台高度：從影片與照片推算，還待現場量測。

這不是施工圖或竣工測繪。每個物件點下去，右側都會標出它的尺寸屬於實測、地圖換算、原廠規格、推算或推測哪一級。
